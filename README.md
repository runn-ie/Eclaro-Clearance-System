# Eclaro Academy Clearance System

## Start
1. Extract this ZIP.
2. Open `index.html` in a modern browser to use the student clearance portal.
3. Open `admin-dashboard.html` for the updated administrator dashboard.

## Included
- `index.html` / `clearance-system.html` — student portal
- `admin-dashboard.html` — newest admin dashboard (Faculty / Staff admin section removed)
- `form-designer.html` — clearance document visual editor
- `test-fields.html` — test mapped clearance fields
- `preview-file.html` — document preview and print-to-PDF page

## Notes
- This is a front-end HTML/CSS/JavaScript package. It does not provide a production server, database, authentication service, or persistent multi-user storage.
- The document designer/test/preview flow uses browser storage and PDF.js from a CDN, so internet access is needed for the PDF.js library.
- If your pages expect school logo image files, add the matching logo assets beside the HTML files.
